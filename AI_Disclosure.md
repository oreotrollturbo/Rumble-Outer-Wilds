## Initial yap
I was very tempted to generate this whole file with ChatGPT just as a joke and make it as obvious as 
possible, but then I’d probably get crucified, and it isn't worth the funni. I started to learn to mod properly
back when gpt3 was a thing, and its coding helped me get the hang of minecraft modding. Once I got good enough I
stopped using it mainly because it really wasn't worth the time. Nowdays though, the agents have gotten far too good
to the point where I could probably have one generate most of the things I code, and it would be faster than making them manually.
It is very much the lazy option, the one that would bite me in the ass if I were to overuse it. And so to keep myself
accountable and be a bit more transparent, I decided to make this file with hard set rules on what I will and won't use AI for. 
I don't want to leave my coding skills to rot, and neither do I want people to assume I am some kind of purist that doesn't use AI *cough* Sk- *cough*.
I will *NOT* be cataloguing every single line of code I generate here, though, because frankly, that's too much work, so there will probably be a comment in the code saying it is AI-generated (I'll try to remember).


## What AI *can* be used for
- Helper functions
- Finding issues/Logging
- Large scale refactors of the code (moving code around, not changing it)
- Adding stuff to the UIFramework system settings

<sup><sub>The UIFramework settings don't have any logic, it's just tedious work, the text describing the setting will be written by me.</sub></sup>

## What it was not used for
- Ideas for features (obviously)
- The over all mod structure
- Assets
- At least 75% of the code (so that I can't crutch)
- Entire components/Features

#### None of this includes the InteliJ Rider AI autocomplete since that literally just writes what I would have written.
